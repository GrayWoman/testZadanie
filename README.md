# Network Speed Tester

Скрипт на Python для замера скорости интернет-соединения. Запускается в изолированном и безопасном Docker-контейнере.

## Запуск теста

Для сборки образа и запуска теста выполните две команды в терминале:

1. **Сборка Docker-образа:**
   ```bash
   docker build -t speedtest-app .
   ```

2. **Запуск контейнера:**
   ```bash
   docker run --rm speedtest-app
   ```

*Флаг `--rm` автоматически удалит контейнер с вашего компьютера сразу после завершения замера скорости.*
